Node.js ve npm

npm & npx:
    npm : paketleri kurar. (bugün Tailwind CSS, ileride Express...)
    
    npx : kurulu olan paketi projede ÇALIŞTIRIR.
    
    Örn:
        npm install tailwindcss @tailwindcss/cli -> kurar
        npx @tailwindcss/cli -i ... -o ... --watch -> çalıştırır.

npm install sonrası gelenler : 
    package.json : 
        projenin kimliği gibi. Kurulan kütüphanelerin adı ve sürümleri burada tutulur.

    package-lock.json : 
        kütüphanelerin hangi NET sürümlerle geldiği bu dosyada kilitli tutulur (adından da bir nevi belli zaten)
        Başka bir bilgisayarda aynı sürümlerle gelir.

    node_modules/ : 
        indirilen bütün kütüphanelerin tutulduğu klasör.
        .gitignore'de tutulur -> Github'a gitmez; public dışında -> ziyaretçiye sunulmaz.
    
    npm install : 
        Proje kökünde çalıştırılır.

*** 
Kullanıcıya gösterilecek olan her özellik zaten public klasörünün içerisinde tutulur.
***

install-scripts uyarısı (3 adımlı karar) : 
    1- Listele : 
        npm install-scripts ls

    2- Güvenli mi? : 
        npmjs.com sitesinde;
            -- haftalık indirme sayısı,
            -- kim/hangi proje tarafından yayınlanıyor
        bunlara baktıktan sonra izin ver ya da izin verme.

        Mesela benim projemde @parcel/watcher paketi, kurulum betiğini çalıştırmak için izin istiyordu.

    3- Karar : 
        Önce izinsiz dene.
        Çalışıyorsa izin VERME (en az yetkide tut).
        Hata verirse bilerek approve.

        Benim projemde hata vermediği için bende izin vermedim.
