Tailwind CSS nedir?
    Hazır bileşen (.card, .btn gibi) vermeyen, her biri tek bir CSS özelliği olan, küçük sınıflar
veren bir CSS framework'ü.

Normal CSS;
   .kart { display: flex;              
          background-color: white;
          padding: 1rem;
          border-radius: 0.5rem; }

Tailwind CSS;
     <div class="flex bg-white p-4 rounded-lg">

Bootstrap'tan Farkı;
    Bootstrap hazır bileşen verir, Tailwind parça parça verir.

Nasıl Çalışır?
-- Tailwind motoru HTML/JS dosyalarımı tarar, kullandığım sınıfları bulur ve onların CSS'ini
output.css'e yazar.

-- Kullanmadığım sınıflar dosyaya girmez; dosya, kullandığım farklı sınıf sayısı kadar büyür.

Sıfır Çalışma Zamanı;
-- Tailwind, ben kodu yazıp kaydederken arkada çalışır.

--Ziyaretçi siteyi açtığında Tailwind hiç çalışmaz; tarayıcı sadece hazır output.css'i okur.
(CDN'de ise bu iş her ziyaretçinin tarayıcısında yapılır. >> gerçek projede bu yok)

Kurulum (tailwindcss.com -> Tailwind CLI, v4)

1- npm install tailwindcss @tailwindcss/cli
    tailwindcss : motor (sınıfları bulup CSS üreten)
    @tailwindcss/cli : motoru terminalden çalıştıran araç (direksiyon)

    -- Burayı motor-direksiyon mantığıyla bağdaştırabiliriz.
    Ayrıca v4'te ayrı paketler, herkesin CLI'a ihtiyacı yok.

2- src/input.css içine : @import "tailwindcss";

3- npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch 
    npx : kurulu paketi çalıştırır. 
    (npm : paketi kurar
    npx : paketi çalıştırır
    )

    -i : okuyacağı dosya : input

    -o : yazacağı dosya : output

    --watch : her kaydettiğimde CSS'i yeniden üretir.

4- HTML'in head'ine :
    <link href="./output.css" rel="stylesheet">

    Neden output?
        Tarayıcı @import "tailwindcss"; satırından bir şey anlamaz; motorun ürettiği gerçek
    CSS output.css'te.

4) Grid ve flex ile hizalama
GRID (footer'ın 3 sütunu):
- grid            -> ızgara düzenini açar (yoksa grid-cols çalışmaz)
- grid-cols-1     -> telefonda tek sütun, hepsi alt alta
- md:grid-cols-3  -> 768px ve üstünde 3 sütun yan yana
- gap-6           -> sütunlar arası 24px boşluk (6 x 4px)
- justify-items-center -> her KUTUYU sütununun ortasına koyar,
                          içindeki satırlar sola yaslı kalır
FLEX (footer'ın alt katı):
- flex            -> esnek düzeni açar (yoksa flex-col çalışmaz)
- flex-col        -> yukarıdan aşağı dizer
- md:flex-row     -> 768px ve üstünde soldan sağa dizer
- justify-between -> ilki en başa, sonuncu en sona, boşluk arada
- items-center    -> flex-col'da yatay ortalar
                     (grid'de dikey ortaladı -> Kişisel aşağı kaydı)
YAZI:
- text-center md:text-left -> telefonda her satır ortalı,
                              768px ve üstünde sola hizalı
MOBİL ÖNCELİKLİ: önce telefon için yaz, md: ile geniş ekranı değiştir.


6) Boşluklar, rem, kontrast, önekler
BOŞLUK:
- p = padding (kutunun İÇİ), m = margin (kutunun DIŞI)
- yön: t = üst, b = alt, l = sol, r = sağ,
       x = sol + sağ, y = üst + alt
- 1 birim = 4px (mt-5 = 20px, px-6 = 24px)
- İki eleman arasına boşluk -> margin (başlığın altına mb-2)
REM:
- rem = root em. 1rem = <html>'in yazı boyutu = varsayılan 16px
- Tailwind boşluk birimi 4px, rem ile karıştırma
