### F) 14. OGRENDIGIM KURALLAR -> 21.10 maddelerinin altina, "15. TAILWIND KARTIM" basliginin USTUNE

22.10:
- return fonksiyondan HEMEN cikar; alttaki kod calismaz. "Liste bossa
  mesaj goster ve cik" icin ideal.
- Ortak is = ortak fonksiyon (applyFilters). Dinleyiciler DISARIDA kalir
  ve fonksiyonu cagirir. Dinleyiciye isim parantezsiz verilir
  (applyFilters), simdi calistirmak icin parantezli (applyFilters()).
- data-level (HTML) <-> button.dataset.level (JS).
- || = "ya da", && = "ve". Tek & baska bir sey, kullanma.
- Template literal: `Seviye: ${item.level}` sadece BACKTICK ile calisir.
  Tek/cift tirnakta ${} duz yazi kalir. Alternatif: 'Seviye: ' + item.level
- classList.add('x') ekler, classList.remove('x') kaldirir.
  Secili buton: once HEPSINDEN remove, sonra basilana add.
- Ic ice forEach'te icteki degiskene farkli ad ver (otherButton).
- Tailwind sinif adi = on ek + renk adi; renk adi @theme'deki
  --color-'dan sonrasi: --color-primary -> bg-primary, text-primary.
- "x:" (iki noktali) = durum on eki (hover:, dark:, active: = basili
  tutulurken). Kendi sinif adim iki noktasiz yazilir (active).
- margin (mt/mb) DISARIYA, padding (pt/pb) ICERIYE bosluk.
- flex = yan yana sirala; grid = sutunlu izgara. gap ikisinde de aralik.
- span ve label varsayilan inline: margin icin inline-block, kendi
  satirina almak icin block.
- w-full = tam genislik; max-w-md = ust sinir (buyuk ekranda durdurur).
- Favicon: public/favicon.svg + head'e rel="icon" link. Yol sayfaya gore:
  index.html -> favicon.svg, pages/*.html -> ../favicon.svg.
- SVG duz metin dosyasidir; & yerine &amp; yazilir.
- git switch -c yeni-dal = olustur + gec (-c'siz sadece var olana gecer).
- git push -u: yerel dali uzaktakine baglar; sonra sadece git push yeter.
- Commit edilmemis degisiklik dal degistirince seninle gelir. Karismasin
  diye git add'e dosyalari tek tek yaz.
- Commit'ten sonra yapilan degisiklik commit'e girmez. Dal degistirmeyi
  engelleyebilir ("would be overwritten"). git diff --stat = hangi dosyada
  kac satir; git diff dosya = satir satir (- eski, + yeni). Sayfalamadan q ile cik.
- Yerel dali silmek GitHub'dakini silmez: PR sayfasinda "Delete branch"
  ya da git push origin --delete dal-adi; sonra git fetch --prune.
